# Vibe Coding

This repository is for work completed during the **Vibe Coding** online course. It contains course homework, experiments, and the development of a personal application/project.

## Repository structure

Each homework assignment lives in its own numbered folder, using the `NN_HW` naming convention:

```text
01_HW/
02_HW/
03_HW/
...
```

Create a new folder for each assignment and keep its code, notes, and related assets together. Continue the sequence for future homework.

The application or output project can be kept in its own top-level folder, separate from the homework folders, for example:

```text
project/
```

## Getting started

Open the folder for the homework or project you want to work on. Check that folder's README or setup instructions, if provided, for any specific requirements.
